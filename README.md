# portfolio-astro

Source of https://www.enkatsu.org/, built with Astro and Contentful.

## Setup

```shell
nvm use
npm install
cp .env.example .env  # set CONTENTFUL_ACCESS_TOKEN and CONTENTFUL_SPACE_ID
```

## Commands

- `npm run dev` — start the dev server
- `npm run build` — build to `dist/`
- `npm run preview` — preview the build
